# Grupo Velox Autoescuela

Plataforma web profesional en español para la gestión de trámites de permiso de conducir en España.

## Requisitos

- Node.js 18+
- npm

## Instalación

```bash
npm install
npm run dev
```

Abrir: http://localhost:3000

## Producción

```bash
npm run build
npm start
```

## Despliegue recomendado

- Vercel o hosting con HTTPS
- Base de datos PostgreSQL
- almacenamiento privado de documentos
- dominio profesional
